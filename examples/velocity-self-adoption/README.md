# Velocity Self-Adoption Snapshot (2026-09-21)

A worked example: Velocity applying its own experimental decision-level and portable-records
profile to the effort that produced it. These four records are kept as they stood when the
experimental channel was published on 2026-09-21. They are a dated snapshot, not Velocity's
work queue, and nothing in them binds an agent or a project.

| Record | What it shows |
| --- | --- |
| [ARTIFACTS.md](ARTIFACTS.md) | An artifact index: where each record lives, who owns it, how it is updated and recovered |
| [TODO.md](TODO.md) | A Markdown work queue under the work contract, with proof obligations per item |
| [INITIATIVES.md](INITIATIVES.md) | An initiative record: outcome, plan, and assessment |
| [PORTFOLIO.md](PORTFOLIO.md) | A portfolio record that keeps investment posture separate from work state |

Read them as an illustration of the record shapes in the
[decision levels](../../docs/DECISION-LEVELS.md) and
[portable project records](../../docs/PORTABLE-PROJECT-RECORDS.md) documents, not as current
status. They name the agent that did the work as the Coordinator's executor; that is a record of
who acted on that day, not a role assignment. Statements in them about the current stable release
were true when written. Velocity's live work is tracked by the maintainer outside this public
repository.
